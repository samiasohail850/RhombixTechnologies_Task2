Social Media Website UI
Description
A frontend-based social media website UI developed using HTML, CSS, and JavaScript as part of Internship Task 2. The project focuses on layout design, UI components, and basic interactivity.
Features
Responsive navigation bar and sidebars
Stories section and post feed UI
Settings menu toggle
Dark/Light mode using localStorage
Technologies Used
HTML5
CSS3
JavaScript
Note
This is a static frontend project with no backend functionality.
